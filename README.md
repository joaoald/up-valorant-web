# Guia Tático VALORANT

Trabalho desenvolvido para a disciplina de **Desenvolvimento Front-End para Web**.

**Autores:**
- João Manuel Ferreira Alduan
- Isaque Almeida Costa

## Sobre o projeto

Este projeto consiste em um site estático com informações e guias sobre o jogo VALORANT. O objetivo foi aplicar os conceitos vistos em aula utilizando HTML, CSS, Bootstrap e JavaScript.

O site conta com páginas sobre os agentes, mapas, armas (arsenal), meta atual do jogo, guias específicos (Ascent e Jett), área da comunidade, um montador de composição de time e uma página de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Como executar

Basta clonar ou baixar o repositório e abrir o arquivo `index.html` diretamente no navegador.

A documentação completa do trabalho também está disponível na pasta `doc/`.
